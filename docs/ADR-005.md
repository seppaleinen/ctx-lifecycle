# ADR-005: Expanded Phase 1 Scope

**Date:** 2026-10-30
**Status:** Accepted
**Deciders:** Wayfinder Map #4

---

## Context

Original research brief defined Phase 1 as MVP (manual switching + basic state machine + hooks + token counting + hand-off summaries). User requested expansion beyond MVP to deliver a production-ready feature set in a single phase.

## Decision

Phase 1 includes all originally-planned Phase 1 + Phase 2 features:

- **A) Automatic pool swapping on test detection** — Bash tool hook intercepts test commands and auto-transitions to DEBUGGING
- **B) Pool persistence to disk implementation** — JSON via `ctx.storage` API (Workstream 2, pending)
- **C) Full state machine with DEBUGGING and COMPLETE states** — 4 states, 6 valid transitions
- **D) Configuration system for pool rules** — `ContextPagerConfig` with per-pool token budgets (Workstream 3, pending)
- **E) Basic validation harness** — Metrics collection, Pass@1 tracking, hallucination detection (Workstream 4, pending)

## Consequences

- Delivers production-ready feature set in single phase
- Validates full architecture end-to-end
- Longer Phase 1 timeline (4 weeks vs 2 weeks)
- Higher initial complexity
- Workstream 1 (Foundation) delivers the core: plugin entry, types, router, state machine, summary generator, and 26 unit tests
